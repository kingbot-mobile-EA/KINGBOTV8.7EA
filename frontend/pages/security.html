Platform Security

Last updated: September 2025

Security is the foundation of the KingBot V8.7 platform. Every layer — from authentication to API communication to EA bridge connectivity — is designed with protection against unauthorized access, data breaches, and malicious activity.

Authentication & Identity

Email Verification

Every account requires email confirmation via a cryptographic token before activation. Unverified accounts cannot subscribe or connect EAs.

Phone SMS OTP

Phone number verification using one-time passcodes sent via SMS. Provides a second identity factor and enables SMS-based trade alerts.

Bcrypt Password Hashing

Passwords are never stored in plaintext. We use bcrypt with a work factor of 12, making brute-force attacks computationally infeasible.

JWT Session Tokens

Stateless JSON Web Tokens with expiration. No server-side session store means nothing to steal. Tokens are signed with a secret key.

API & Infrastructure Security

Helmet Security Headers

HTTP security headers including CSP, X-Frame-Options, X-Content-Type-Options, and HSTS protect against XSS, clickjacking, and MIME sniffing.

Rate Limiting

API endpoints are rate-limited to prevent brute-force attacks, credential stuffing, and abuse. Auth endpoints have stricter limits.

CORS Policy

Strict Cross-Origin Resource Sharing configuration. Only the official KingBot frontend origin can make authenticated API requests.

TLS Encryption

All communication between the frontend, backend, and EA bridge is encrypted in transit. No plaintext data ever crosses the network.

EA Bridge Security

The mobile EA bridge uses your license key as an authentication token. Every status update and command is validated against your active subscription. The bridge endpoint rejects requests with invalid, expired, or plan-mismatched license keys. No one can control your EA without both your account credentials and a valid license key.

What You Should Do

  • Use a unique, strong password (12+ characters, mixed case, numbers, symbols)
  • Keep your email and phone number verified and up to date
  • Never share your license keys — they grant EA control
  • Review your activity log regularly in Profile settings
  • Report any suspicious activity immediately
